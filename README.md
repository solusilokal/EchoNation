# EchoNation - Rental Alat Musik & Sound System

Mini website interaktif untuk penyewaan instrumen musik dan peralatan audio standar panggung & studio rekaman profesional.

Repository: [https://github.com/solusilokal/EchoNation](https://github.com/solusilokal/EchoNation)

## Fitur Utama

- **Katalog Interaktif**: Pilihan alat musik (Gitar & Bass, Drum & Perkusi, Keyboard & Synth, Sound System).
- **Filter Kategori**: Menyaring instrumen berdasarkan kategori yang diinginkan.
- **Formulir Booking Cepat**: Terintegrasi langsung dengan chat WhatsApp resmi admin EchoNation.
- **FAQ Interaktif**: Pertanyaan umum seputar sistem rental, antar-jemput, dan ketentuan sewa.
- **Testimoni**: Review musisi dan EO.
- **Modal Berbagi**: Fitur share langsung via tautan atau WhatsApp.
- **Dukungan Mobile-First**: Dioptimalkan untuk tampilan smartphone dengan Floating CTA Button.

## Teknologi

- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (Icons)
- **GitHub Actions & Pages** (CI/CD Deployment)

## Menjalankan Secara Lokal

```bash
# 1. Install dependensi
npm install

# 2. Jalankan development server
npm run dev

# 3. Build untuk produksi
npm run build
```

Atau cukup jalankan file `preview.bat` pada sistem operasi Windows.
